# Security Policy

## Supported versions

Before 1.0, security fixes target the latest published minor release. Older
pre-1.0 builds may need to upgrade rather than receive a backport.

## Report a vulnerability

Use GitHub Private Vulnerability Reporting from the repository Security tab.
Do not put credentials, private PDF content, file paths, security-scoped
bookmarks, or local configuration in a public issue.

Include the affected Dogear and macOS versions, impact, and a minimal
reproduction using a synthetic or freely licensed PDF. If private reporting is
not available, open a public issue with no sensitive details and ask the
maintainer to enable a private channel.
