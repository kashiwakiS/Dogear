# Dogear 0.3.1

发布日期 / Release date: 2026-11-04

## 中文

- PDF 文字备注支持字体、字号与颜色调整，并可恢复原始样式。
- 批注编辑采用原生文本输入，支持独立的文本撤销与重做；未完成的编辑会在关闭或退出时受到保护。
- 文档、选区、批注与导出流程统一使用共享原生 API，让阅读和编辑行为更加一致。

需要 macOS 14.0 或更高版本。当前发行包已使用开发者账户签名。

## English

- PDF text notes offer font, size and color controls, with the option to restore the original style.
- Annotation editors use native text input with independent text undo and redo, and protect unfinished edits when closing or quitting.
- Document, selection, annotation and export workflows use shared native APIs for more consistent reading and editing behavior.

Requires macOS 14.0 or later. The current distribution package is signed with the developer account.
